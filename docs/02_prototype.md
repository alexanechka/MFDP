# Прототип: оценка кредитного рейтинга по открытой отчётности

## 1. Ключевая гипотеза

Сервис, который по ИНН определяет кредитный рейтинг нефинансовой компании
**только на открытых данных** (отчётность RFSD и публичные рейтинги агентств), совпадает
с рейтингом агентства с точностью **±1 рейтинговая ступень не менее чем в 80% случаев
на отложенной тестовой выборке** и превосходит простые модели (Altman Z-score,
логистическая регрессия).

**Критерий:** если порог достигнут, считаем, что реализация сервиса возможна и его можно
внедрять как **внутренний инструмент** для **аналитиков аналитического департамента
компании-брокера** в сценарии **первичного скрининга эмитентов**.

**Монетизация:** экономия рабочего времени аналитиков: первичная оценка эмитента занимает
минуты вместо 2–4 часов ручного анализа (допущение, уточняется замером), а освободившееся
время идёт на углублённый анализ и покрытие большего числа эмитентов.

**Срок проверки:** 2 недели.   

**Причина:** методики рейтинговых агентств опираются на финансовые коэффициенты, которые рассчитываются по открытой отчётности.

## 2. Ключевые метрики

| Тип | Метрика | Целевое значение | Baseline | Способ измерения | Частота |
|---|---|---|---|---|---|
| Техническая | Точность ±1 ступень | ≥ 0.80 | Altman Z-score, логистическая регрессия, «самый частый класс» | Отложенная выборка: разбиение по компаниям и по времени | Каждая итерация модели |
| Техническая | Прирост над лучшим бейзлайном (±1 ступень) | ≥ +5 п.п. | Лучший бейзлайн | Та же отложенная выборка | Каждая итерация модели |
| Техническая | ROC-AUC: верхняя (A и выше) / нижняя часть шкалы | ≥ 0.80 | Те же бейзлайны | Та же отложенная выборка | Каждая итерация модели |
| Техническая | Покрытие: доля ИНН, для которых найдена отчётность | ≥ 95% | — | Логи сервиса | Каждый запрос / итог теста |
| Техническая | Время ответа сервиса | ≤ 2 с | — | Логи сервиса | Итог теста |
| Продуктовая | Время первичной оценки эмитента | ≤ 5 мин | 2–4 часа ручного анализа (допущение, уточняется замером на 3–5 компаниях) | Замер на тестовых компаниях | До теста и в конце |
| Продуктовая | Доля оценок, с которыми согласен аналитик | ≥ 70% | — | Экспертная проверка 20–30 компаний | В конце теста |
| Продуктовая | Полезность объяснений (оценка 1–5) | ≥ 4 | — | Опрос тестировщиков | В конце теста |

## 3. Что входит в прототип и что нет

| Входит | Почему |
|---|---|
| Данные: рейтинги Эксперт РА, НРА, НКР, приведённые к единой шкале (таблица сопоставления шкал Банка России), + отчётность RFSD | Без данных гипотезу не проверить |
| Модель: бейзлайны + градиентный бустинг, укрупнённые группы рейтинга | Ядро гипотезы |
| Объяснение оценки (топ-5 факторов, SHAP) | Без объяснения аналитик не доверяет оценке |
| Поиск по ИНН: прогноз группы, вероятности, факторы, текущий рейтинг агентства (если есть) | Основной сценарий пользователя |

| Намеренно не делаем | Почему |
|---|---|
| Модель на данных США | Не нужна для проверки гипотезы на российских эмитентах; остаётся запасным вариантом |
| Мониторинг портфеля, алерты, пакетная обработка | Другой сценарий; гипотеза проверяется на скрининге |
| Авторизация, интеграция с системами брокера | Не влияет на проверку ценности |
| Банки и страховые компании | Нет в RFSD, другие методики оценки |
| Автообновление данных | Для теста достаточно статичного среза |
| Масштабирование, полное покрытие тестами | По принципам прототипа откладывается до подтверждения гипотезы |

## 4. Готовые блоки и собственная разработка

| Берём готовое | Делаем сами | Почему своё критично |
|---|---|---|
| RFSD (отчётность всех компаний РФ, CC BY 4.0) | Сбор рейтингов: парсинг Эксперт РА (с соблюдением robots.txt), выгрузки НРА и НКР | Готового открытого набора рейтингов нет; это таргет модели |
| Таблица сопоставления шкал Банка России | Единая шкала и укрупнённые группы | Без этого рейтинги разных агентств несопоставимы |
| scikit-learn, CatBoost, SHAP | Привязка отчётности к дате рейтинга | Защита от утечки, иначе метрики завышены |
| FastAPI, Streamlit, Docker | Расчёт финансовых коэффициентов по методикам агентств | От этого зависит и качество, и понятность объяснений |
| DVC | Схема валидации (по компаниям и времени) | Иначе нельзя честно сравнить модель с бейзлайном |

## 5. Главный риск

На открытых данных нельзя построить модель, которая воспроизводит рейтинг
агентства с точностью, достаточной для скрининга: выборка мала (сотни компаний),
а рейтинг учитывает качественные факторы, которых нет в отчётности.
Если риск реализуется, сервис не экономит время аналитика: ему всё равно
придётся проверять каждую компанию вручную.

## 6. Формат прототипа

Веб-приложение на Streamlit поверх API (FastAPI) в Docker:
- на входе ИНН компании;
- на выходе карточка: прогнозируемая группа рейтинга, вероятности по группам,
  топ-5 факторов с направлением влияния, текущий рейтинг агентства (если есть).

## 7. Критерии остановки теста

| Исход | Условие | Действие |
|---|---|---|
| Успех | ±1 ступень ≥ 0.80 и лучше бейзлайна на ≥ 5 п.п. | Развиваем сервис |
| Доработка | ±1 ступень 0.70–0.80 или прирост < 5 п.п. | Не более 2 итераций: признаки, укрупнение классов |
| Разворот | После 2 итераций ±1 ступень < 0.70 или модель не лучше бейзлайна | Бинарная задача (верх/низ шкалы) или данные США как основные |
| Смена темы | Разворот не дал результата или после сопоставления < 300 записей | Согласование новой темы с руководителем |
| Ограничение по времени | Прошло 2 недели | Фиксируем результат как есть и принимаем решение |

# Прототип: оценка кредитного рейтинга по открытой отчётности

## 1. Ключевая гипотеза

**Если** мы предлагаем модель оценки кредитного рейтинга нефинансовых компаний
**только на открытых данных** (отчётность RFSD и публичные рейтинги агентств) **для** аналитиков
аналитического департамента компании-брокера **в сценарии** первичного скрининга эмитентов,
**то** она совпадёт с рейтингом агентства с точностью до ±1 рейтинговой ступени **не менее чем в 80% случаев**
на отложенной тестовой выборке и превзойдёт бейзлайны (Altman Z''-score, логистическая
регрессия) **в течение** 2 недель проверки, **потому что** методики агентств опираются
на коэффициенты из открытой отчётности.

**Монетизация** - экономия рабочего времени аналитиков: первичная оценка эмитента занимает
минуты вместо 2–4 часов ручного анализа, а освободившееся
время идёт на углублённый анализ и покрытие большего числа эмитентов.

**Срок проверки:** 2 недели.
- **Неделя 1 - техническая проверка:** сборка датасета, бейзлайны и CatBoost,
  метрика ±1 ступень на тестовой выборке. По итогам принимается решение, продолжать ли работу.
- **Неделя 2 - доработка и продуктовая проверка:** до 2 итераций улучшения модели
  (если нужно), сборка Streamlit-приложения для аналитиков и продуктовые метрики
  с 2–3 аналитиками департамента: время оценки, согласие с оценками, полезность объяснений.

## 2. Ключевые метрики

| Тип | Метрика | Целевое значение | Baseline | Способ измерения | Частота |
|---|---|---|---|---|---|
| Техническая (гипотеза) | Точность ±1 ступень | ≥ 0.80 | Лучший из бейзлайнов: «самый частый класс», Altman Z''-score, логистическая регрессия (значение определяется на неделе 1) | Отложенная выборка: разбиение по компаниям и по времени | Каждая итерация модели |
| Техническая (гипотеза) | Прирост над лучшим бейзлайном (±1 ступень) | ≥ +5 п.п. | Лучший бейзлайн | Та же отложенная выборка | Каждая итерация модели |
| Техническая | Время определения рейтинга одной компании (расчёт признаков + прогноз модели) | ≤ 1 с | Определяется на неделе 1 | Замер в Jupyter (`%timeit`) на компаниях тестовой выборки | Каждая итерация модели |
| Продуктовая (монетизация) | Время первичной оценки эмитента | ≤ 5 мин | 2–4 часа ручного анализа | Аналитик оценивает 3–5 компаний сначала вручную, затем с помощью приложения | До начала и в конце теста |
| Продуктовая | Доля оценок, с которыми согласен аналитик | ≥ 70% | Согласие аналитика с прогнозом лучшего бейзлайна на тех же компаниях | Экспертная проверка 20–30 компаний тестовой выборки | В конце теста |
| Продуктовая | Полезность объяснений (оценка 1–5) | ≥ 4 | - | Опрос аналитиков | В конце теста |

## 3. Что входит в прототип и что нет

| Входит | Почему |
|---|---|
| Данные: рейтинги Эксперт РА, НРА, НКР, приведённые к единой шкале (таблица сопоставления шкал Банка России), + отчётность RFSD | Без данных гипотезу не проверить |
| Модель: бейзлайны + градиентный бустинг, прогноз рейтинговой ступени | Ядро гипотезы |
| Объяснение оценки (топ-5 факторов, SHAP) | Без объяснения аналитик не будет доверять оценке |
| Локальное Streamlit-приложение для аналитика: выбор компании из тестовой выборки, прогноз рейтинга, факторы, фактический рейтинг агентства для сравнения | Аналитик не работает с кодом; без интерфейса нельзя измерить продуктовые метрики |

| Намеренно не делаем | Почему |
|---|---|
| API (FastAPI), контейнеризация, развёртывание на сервере | Для теста с 2–3 аналитиками достаточно локального приложения |
| Поиск по произвольному ИНН | Для проверки гипотезы достаточно тестовой выборки; поиск по любому ИНН требует актуальной базы отчётности |
| Модель на данных США | Не нужна для проверки гипотезы на российских эмитентах; остаётся запасным вариантом |
| Мониторинг портфеля, алерты, пакетная обработка | Другой сценарий; гипотеза проверяется на скрининге |
| Авторизация, интеграция с системами брокера | Не влияет на проверку ценности |
| Банки и страховые компании | Нет в RFSD, другие методики оценки |

## 4. Готовые блоки и собственная разработка

| Компонент | Готовое / своё | Что используем | Почему так |
|---|---|---|---|
| Отчётность компаний | Готовое | RFSD (отчётность всех компаний РФ, CC BY 4.0), чтение через DuckDB | Бесплатная альтернатива платному API ГИР БО; данные уже приведены к единому формату |
| Сопоставление шкал агентств | Готовое | Таблица сопоставления шкал Банка России (11.07.2024) | Официальная методика сопоставления - своя не требуется |
| Модели и объяснения | Готовое | Jupyter, pandas, scikit-learn, CatBoost, SHAP | Стандартный стек, достаточный для прототипа |
| Интерфейс для аналитика | Готовое | Streamlit | Интерфейс на том же Python за ~1 день, без отдельной фронтенд-разработки |
| Сбор рейтингов | **Своё** | Парсинг Эксперт РА (с соблюдением robots.txt), выгрузки НРА и НКР | Готового открытого набора рейтингов нет; это таргет модели |
| Единая шкала | **Своё** | Нормализация записей рейтингов, учёт сдвига шкалы НРА | Без этого рейтинги разных агентств несопоставимы |
| Привязка отчётности к дате рейтинга | **Своё** | Берётся только отчётность, опубликованная до даты рейтинга | Защита от утечки, иначе метрики завышены |
| Финансовые коэффициенты | **Своё** | Расчёт по аналогии с методиками агентств | От этого зависит и качество, и понятность объяснений |
| Схема валидации | **Своё** | Разбиение по компаниям и по времени | Иначе нельзя честно сравнить модель с бейзлайном |

## 5. Главный риск

По открытой отчётности не удастся оценить кредитный рейтинг компании
с нужной точностью (±1 ступень не менее чем в 80% случаев), потому что рейтинг учитывает
качественные факторы, которых нет в отчётности, а методики агентств различаются.

## 6. Формат прототипа

Два компонента:

**Jupyter-ноутбук (для разработчика):** обучение модели и бейзлайнов, сводные метрики
на всей тестовой выборке (точность ±1 ступень, сравнение с бейзлайнами, время определения
рейтинга); обученная модель сохраняется в файл.

**Локальное Streamlit-приложение (для аналитика):** загружает обученную модель,
код аналитику видеть не нужно. Приложение запускается на компьютере разработчика;
аналитики работают с ним на этом компьютере или через демонстрацию экрана.
- на входе - компания из тестовой выборки (выбор из списка);
- на выходе карточка: прогнозируемый рейтинг, вероятности, топ-5 факторов (SHAP)
  с направлением влияния и фактический рейтинг агентства для сравнения.

## 7. Критерии остановки теста

| Исход | Условие | Действие |
|---|---|---|
| Успех | ±1 ступень ≥ 0.80 и лучше бейзлайна на ≥ 5 п.п. | Развиваем сервис |
| Ранний разворот (после недели 1) | ±1 ступень < 0.60 | Сразу переходим к развороту, без итераций доработки |
| Доработка | ±1 ступень 0.60–0.80 или прирост < 5 п.п. | Не более 2 итераций: подбор признаков, объединение редких классов внизу шкалы, настройка модели |
| Разворот | После 2 итераций порог 0.80 не достигнут или модель не лучше бейзлайна | Бинарная задача (верх/низ шкалы) или данные США как основные |
| Непригодность для пользователя | Технический порог достигнут, но аналитики согласны с оценками < 50% | Модель не используется для скрининга; разбираем расхождения с аналитиками |
| Смена темы | Разворот не дал результата | Согласование новой темы с руководителем |
| Ограничение по времени | Прошло 2 недели | Фиксируем результат как есть и принимаем решение |
